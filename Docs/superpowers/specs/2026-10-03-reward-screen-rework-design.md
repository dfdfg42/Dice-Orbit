## 1. 지금 화면의 문제

| # | 문제 | 근거 |
|---|------|------|
| 1 | 타일이 전부 같은 모양이고 글자가 중복된다 | 이름표 "골드 +50" + 타일 안 "골드 +50", 아이콘 없음 |
| 2 | 핵심 결정(모디파이어 3택1)이 하위 창 2단계 뒤에 있다 | 강화 타일 → 캐릭터 선택 → 그제야 선택지 3장 |
| 3 | 선택지를 다시 굴릴 수 있다 | 캐릭터 선택 후 취소 → 재진입 시 `GetRandomChoicesFor`가 새로 뽑음 |
| 4 | 고민 없는 보상도 클릭해야 한다 | 골드 타일 클릭. 한 전투당 최대 7클릭 (골드·강화·캐릭터·모디파이어·주사위·슬롯·계속) |
| 5 | 주사위 보상이 빈 주사위 면으로만 보인다 | 특수 주사위 15종 전부 Icon 없음 → 호버해야 6면·효과가 나옴 |
| 6 | 못 받은 보상이 조용히 사라진다 | [계속]이 미수령 타일을 경고 없이 버림 |

8월 플레이테스트의 "템포 느림" 피드백으로 전투는 클릭을 줄였는데, 보상은 그대로 남아 있었다.

## 2. 목표 / 비목표

**목표**
- 클릭은 결정에만 쓴다 — 전투당 4클릭 이하 (카드·장착·덱 주사위·교체).
- 한 장의 시트에서 "무엇을 얻었고, 지금 무엇을 골라야 하는지"가 읽힌다.
- 선택지는 보상 진입 시 한 번만 굴린다.
- 크림 종이 + 잉크 방향과 스킨 역할 카탈로그(전용 스프라이트) 규칙을 지킨다.

**비목표**
- 보상의 종류·수치(골드 50, 포션 35%, 엘리트 유물, 특수 주사위 드로우)는 바꾸지 않는다.
- 모디파이어·주사위에 개별 아이콘 12+15장을 그리지 않는다 (계열 아이콘 4장으로 해결).
- 세이브 구조는 건드리지 않는다 (보상 화면은 저장 지점이 아니다 — 저장은 맵 진입 시).

## 3. 흐름 — 한 시트, 세 박자

```
[전투 승리] → 시트 팝인
  ① 전리품 (자동)   골드 카운트업 · 유물 · 포션 칩이 차례로 붙는다. 클릭 없음.
  ② 강화 (결정)     모디파이어 카드 3장 + 파티 초상 줄 → [○○에게 장착]
  ③ 주사위 (결정)   새 주사위 카드 ↔ 내 덱 카드 → [교체] 또는 [받지 않기]
→ 마지막 결정이 끝나면 도장 연출 후 자동으로 다음 상태(모집/맵)
```

- 전리품 줄은 시트 위쪽에 계속 남아 요약 역할을 한다.
- 진행 표시(전리품 · 강화 · 주사위 점 3개)가 현재 박자를 알려 준다. 없는 박자는 점도 없다.
- 박자가 하나도 없으면(강화 불가 + 주사위 없음) 마지막에 [계속] 한 번.
- 포션 가방이 가득 차 포션을 못 받았으면 자동으로 넘어가지 않고 [계속]을 눌러야 한다 (조용히 사라지지 않게).

### ② 강화 박자
- 카드 3장: 계열 아이콘(위치/주사위/콤보/생존) · 이름 · 설명 · 상태 줄.
- 파티 초상 줄: 생존 캐릭터 초상 + 이름. 기본 선택 = 첫 생존 캐릭터.
- 상태 줄은 **선택된 캐릭터 기준**: `신규` / `중첩 1 → 2` / `최대 중첩`(장착 불가, 카드 흐림).
- 카드를 고르면 그 카드를 못 받는 캐릭터의 초상이 흐려진다. 초상 호버 = 그 캐릭터의 현재 모디파이어 목록 툴팁.
- 주 버튼: 카드 미선택 `카드를 고르세요`(비활성) → 선택 시 `○○에게 장착`.
- 보조 버튼 `건너뛰기`: 한 번 누르면 `정말 건너뛸까요?`로 바뀌고 2초 안에 다시 눌러야 확정 (오클릭 방지).

### ③ 주사위 박자 (특수 주사위가 뽑혔을 때만)
- 왼쪽 "새 주사위" 큰 카드: 이름(등급 색) · 등급 · 6면 · 사용 효과 · 설명 — 호버 없이 전부 보인다.
- 오른쪽 "내 덱": 덱 주사위마다 작은 카드(이름 · 6면 · 효과 한 줄). 클릭 = 교체 대상 선택.
- 주 버튼: `바꿀 주사위를 고르세요`(비활성) → `교체`. 보조 버튼 `받지 않기`.

### 전리품 칩
- 골드: 전리품 칩(동전 아이콘) + `+N` 카운트업. 진입 즉시 지갑에 들어간다 (유물 보너스 포함).
- 유물(엘리트): 아이콘 + 이름, 즉시 획득. 호버 = 설명.
- 포션(35%): 빈 슬롯이 있으면 즉시 획득. 가득 차면 칩이 `가방 가득` 상태가 되고, 전리품 줄 아래에 "버릴 포션 고르기" 줄이 나온다 — 가진 포션을 누르면 그걸 버리고 새 포션을 받는다. 그냥 두면 포기.

## 4. 규칙 변경 (밸런스에 닿는 것)

| 항목 | 이전 | 이후 | 이유 |
|------|------|------|------|
| 모디파이어 제시 | 캐릭터를 먼저 고르면 그 캐릭터 맞춤 3장 | **공용 3장을 먼저 보고 대상을 고른다** | 무엇을 줄지가 결정의 핵심 — 카드를 봐야 대상을 정할 수 있다 |
| 제시 풀 | 선택 캐릭터가 장착 가능한 종류 | 생존 파티원 중 1명이라도 장착 가능한 종류 | 공용 12종은 3중첩 상한만 다르다 |
| 재굴림 | 취소→재진입으로 가능 | 불가 (진입 시 1회 고정) | 악용 제거 |
| 골드·유물·포션 | 타일 클릭 수령 | 자동 수령 | 손해 없는 보상에 클릭을 쓰지 않는다 |
| 주사위 | 받기 선택형 | 동일 (`받지 않기`) | 교체는 손해일 수 있다 |

- 에디터 소유 패턴: 정적 프레임과 템플릿은 씬에 있고 코드는 내용만 채운다. 런타임 생성 폴백은 없다 — 슬롯이 비면 에러.
- 템플릿은 `RewardCanvas/Templates` 아래 비활성 오브젝트 4개. 런타임에 복제해 `Bind`한다.
- 뷰 컴포넌트는 데이터를 받아 그리기만 하고, 선택·확정 규칙은 `RewardUI`가 쥔다.

## 7. 연출 (코루틴, 0.6초 이내)

- 시트 팝인 0.18s (scale 0.94→1 + 알파).
- 전리품 칩 0.08s 간격 팝, 골드 0.4s 카운트업.
- 카드 선택: 1.04배 + 나머지 카드 알파 0.6.
- 확정: 도장(`장착!` / `교체!`)이 1.5배에서 찍히며 0.45s 유지 → 다음 박자로 교차 페이드 0.15s.

## 10. 구현 결과 (2026-10-03)

- 커밋: 로직(`RewardBundle/Roller/Flow`, `ModifierFamily`, 파티 풀) → 스킨 역할·아트 → UI·스캐폴드·씬 → 문서.
- 아트: 힉스필드 초안 5 + 최종 5 (선택 카드 4상태, 초상 프레임 4상태, 전리품 칩, 도장, 계열 아이콘 4종) = 15.0 크레딧. 생성 로그 36~37행.
- 스킨: 파트 31 + 버튼 24, 점검기 0. 구 역할 4개(303~306)와 스프라이트 4장 삭제.
- 시트 1320×920. 스펙 §6과 달라진 점: 골드도 `RewardLootChip`을 쓴다 (`RewardGoldBar` 삭제).
- 추가된 규칙: 기본 대상 = 제시 카드 중 하나라도 받을 수 있는 첫 캐릭터. 고른 카드를 현재 대상이 못 받으면 받을 수 있는 첫 캐릭터로 대상이 옮겨 간다.
- 검증: `RewardFlowSelfTests` 11건·`UiSkinSelfTests` 통과. Play 투어 4회(2인·4인 파티, 포션 가방 가득 → 버리고 받기, 전 종류 3중첩 캐릭터, 건너뛰기 2회 확인, 받지 않기) 콘솔 에러 0.
- 미검증: 마무리 박자([계속])의 화면 — 결정 박자가 하나도 없는 보상은 자연 발생 조건(강화 불가 + 특수 주사위 풀 없음)을 Play에서 만들지 않았다. 순서 규칙은 자가 테스트가 덮는다.
- 시스템 문서: `Docs/reward_screen_system.md`.
