# 런 구조 & 노드맵 기획서

> 2026-07-07 기획 논의 확정본. 기존 "8웨이브 직선 진행"을 StS식 노드맵 런으로 개편한다.
> 이 문서가 런 구조·경제·파티·아이템 분류의 진실 소스다. 수치는 전부 초안이며 튜닝 대상.

## 0. 한 줄 요약

**StS식 분기 노드맵(1막 10~12층) 위에서, 전투로만 얻는 성장 재화(모디파이어·골드)를 들고
4인 파티가 점감 부활 스톡을 태우며 보스까지 내려간다.**

---

## 1. 맵 구조

- **형태: StS식 분기 트리.** (원형/궤도 맵 안 — 검토 후 기각: 랩 반복은 밸런스 함정, 원형 강제는 억지)
- **1막 10~12층.** 다막 확장 가능하게 설계하되 당장은 1막만.
- 모든 경로는 층 수가 같다 → "전투 회피 경로"는 구조적으로 없다. 선택은 "어떤 전투·어떤 비전투 노드"다.
- 노드 풀의 60~70%는 전투.

### 층 구성 초안

```
층 1~2      전투 (클리어마다 캐릭터 모집 → 4인 완성)   ← 스크립트된 인트로
층 3~5      전투×2, 이벤트
층 6        엘리트① (첫 유물)
층 7~10     전투×2, 상점, 휴식
층 11       엘리트② or 휴식 (보스 앞 선택)
층 12       👑 보스
────────────────────────────
전투 6~7 · 엘리트 1~2 · 상점 1 · 휴식 1~2 · 이벤트 1~2
```

### 노드 종류

| 노드 | 내용 |
|---|---|
| ⚔️ 전투 | 웨이브 전투 → 골드 + 모디파이어 3택1 (+예고된 주사위 개조 드랍) |
| 💀 엘리트 | 강화 전투 → 유물 직접 드랍 + 상위 보상 |
| 🛒 상점 | 골드 소비: 포션 · 캐릭터 교체 · 유물 |
| 🏕️ 휴식 | 파티 회복 (선택지 구성 미정) |
| 🎲 이벤트 | 주사위 도박 이벤트 (내용 미정 — 주사위 정체성 살리는 자리) |
| 👑 보스 | 막 최종전 |

- **모집 노드 없음** — 파티 완성은 초반 스크립트(§3), 이후 로스터 변화는 상점 교체만.
- **공방 노드 없음** — 주사위 개조는 전투 보상 라인(§6)으로.
- 주사위 개조를 주는 전투는 **맵 노드에 아이콘으로 예고** (StS 불타는 엘리트 수법) → 랜덤 드랍을 경로 선택 재료로.

### 막 확장 구조 (ActDefinition)

```
ActDefinition (ScriptableObject)
├─ 층 수, 노드 풀 가중치
├─ 보장 규칙 (엘리트 최소 1, 보스 앞 휴식 등)
├─ 몬스터 풀 / 엘리트 풀 / 보스
└─ 난이도 커브 (층별 웨이브 강도)

런 = [Act1] → 보스 클리어 → (다음 막 있으면 새 맵, 없으면 승리)
```

2막 추가 = 에셋 하나 만드는 일이 되도록. 맵 생성기는 ActDefinition만 읽는다.

## 2. 경제 — 수도꼭지 규칙

**"전투 없이 성장할 수 있는 경로를 만들지 않는다."** 이게 지켜져야 "전투가 적을수록 유리" 문제가 원천 차단된다.

```
전투 ──→ 모디파이어 (유일한 원천, 3택1)
전투 ──→ 골드 ──→ 상점 (포션 · 캐릭터 교체 · 유물)
엘리트 ──→ 유물 (직접 드랍)
```

- **상점은 모디파이어를 팔지 않는다.** (팔면 "골드만 있으면 전투 없이 성장"이 열림)
- 보스/엘리트는 "전투 N회 분량의 성장"을 전제로 튜닝 → 덜 싸운 파티는 보스 앞에서 청구서를 받는다.
- 유물이 상점에 있어도 골드가 전투산이므로 수도꼭지는 안 깨진다.

## 3. 파티

- **2명 시작** (플레이어 선택) → **1·2번째 노드 클리어마다 모집 1명** (플레이어가 역할군 중 선택, 기존 CharacterSelection 흐름 재활용) → **3층쯤 4인 풀파티 완성.**
- 초반 2전투 = 자연 튜토리얼 (2인: 기본기 → 3인 → 4인: 풀 시스템). 인원수가 곧 주사위 배분 복잡도라 학습 곡선과 난이도 곡선이 일치.
- 성장 축은 인원이 아니라 **모디파이어·유물·주사위 개조**가 담당.

### 캐릭터 교체 (상점)

- **비용: 골드, 대상 캐릭터의 모디파이어 개수에 비례** (리롤 세탁 방지 1)
- **내보낸 캐릭터는 재고에서 소멸** — 왕복 교체 불가 (리롤 세탁 방지 2)
- 새 멤버는 **기존 모디파이어 개수만큼 3택1 재선택** (시그니처 모디파이어는 CanApplyTo 때문에 직접 이전 불가 → 재선택이 유일한 이전 방식)
- 새 멤버는 **풀피 + 부활 스톡 만땅** 입장 — 구멍이 아니라 "비싼 힐/스톡 리셋" 전략으로 인정 (골드가 전투산이라 공짜 아님)

## 4. 죽음 — 점감 부활

- 전투 중 사망 → **그 전투에서는 리타이어** (타일 제거, 주사위 배분 인원 감소) → **전투 종료 후 부활**
- 부활 HP: **1차 75% → 2차 50% → 3차 25% → 4차 사망 = 영구사망** (부활 HP = 남은 스톡 × 25%)
- **한 명이라도 영구사망하면 즉시 런 종료 (게임오버)**
- **전멸도 게임오버 유지** — 부활은 "승리한 전투 종료 후"에만 일어나므로, 스톡이 남아 있어도 전멸하면 부활 기회 자체가 없다 (2026-07-07 구현 중 확정)
- 부활 스톡 회복은 **극히 희소** — 기본 회복 불가, 고급 유물/이벤트 보상 정도만 (밸런스 레버)
- UI: 캐릭터 카드에 부활 핍 3개 (●●● → ●●○ → ●○○)
- 튜닝 지표: **런당 평균 죽음 횟수가 3을 넘나들어야** 시스템이 일한다

## 5. 아이템 분류 — 4계층

| 시스템 | 귀속 | 역할 | 획득 |
|---|---|---|---|
| 모디파이어 | 캐릭터 개인 | 스킬·패시브를 바꿈 (영구) | 전투 3택1 (유일) |
| 유물 | 파티 전역 | **런의 규칙**을 바꿈 (상시) — 주사위 전역·궤도·경제·부활 | 엘리트 드랍, 상점 |
| 포션 | 소모품 | 순간 개입 (1회) | 상점, 전투 드랍(저확률) |
| 주사위 개조 | 주사위 1개 | **확률 그 자체**를 바꿈 (영구) | 예고된 전투 보상, 이벤트 |

경계 규칙:
- 모든 주사위에 걸리는 전역 효과 → **유물** / 특정 주사위 1개의 속성 → **개조**
- 스킬·패시브를 바꾸는 건 → **모디파이어** (다른 시스템이 침범 금지)

### 유물 예시 (방향 제시용)

"매 턴 주사위 눈 1 최소 보정", "상점 20% 할인", "부활 HP +15%p", "궤도 한 바퀴마다 파티 5 회복"

### 포션

- **파티 공용 슬롯 3칸** (슬롯 확장은 유물 거리)
- **전투 중 아무 때나, 행동 소모 없이 사용**
- 중심축 = **주사위 조작**: 재굴림 / 눈 ±1 / 원하는 눈으로(레어) / 여분 주사위(레어) + 회복 / 정화(디버프 해제)
- **부활 스톡 회복 포션은 금지** (희소성 원칙)

### 주사위 개조

- 사용 효과형: "이 주사위 사용 시 사용자 HP 회복" 등
- **눈 분포형: 커스텀 면** — 분산 조절이 빌드 축이 된다:

```
안정 주사위  3,3,4,4,4,4  → 조건 충족률 확보, 큰 눈 포기
도박 주사위  1,1,1,6,6,6  → 하이리스크
저눈 주사위  1,1,2,2,3,3  → 저눈 조건 스킬과 시너지
```

- 주사위 풀은 파티 공용이므로 개조 주사위는 **배분 결정에 새 층위** 추가 ("힐 주사위를 누구에게?")
- 전투 보상 화면에서 모디파이어 3택1과 **별도 줄**로 지급 (3택1 예산 희석 금지)

## 8. 기각된 안 (기록)

- **동심 궤도 맵 / 랩 반복**: 랩 파밍은 밸런스 스윗스팟이 면도날 — "돌 가치가 있으면 무조건 돌고, 없으면 죽은 메커니즘". 일방통행 StS 구조가 정답.
- **모집 노드**: 초반 자동 모집(스크립트)으로 대체. 파티 확장을 런 내내 끌면 게임의 본체(4인 배분)를 늦게 주게 됨.
- **공방(대장간) 노드**: 주사위 개조는 예고된 전투 보상으로 충분. 노드 종류는 얇게 유지.
- **상점 모디파이어 판매**: 수도꼭지 규칙 위반.
