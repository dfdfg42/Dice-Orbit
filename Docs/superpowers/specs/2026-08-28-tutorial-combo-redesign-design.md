# 튜토리얼 콤보 전투 개편 설계

## 목표

튜토리얼 전투 한 판 안에서 플레이어가 다음 규칙을 직접 조작하며 이해하도록 한다.

- 전장은 네 구역이며 구역마다 담당 몬스터가 한 마리씩 있다.
- 주사위를 캐릭터에게 배정하면 그 눈만큼 이동하고, 도착한 구역의 몬스터를 자동으로 공격한다.
- 몬스터 의도와 위험 타일을 보고 위치를 정한다.
- 전사와 도적은 같은 구역의 다른 아군 수에 따라 패시브가 중첩된다.
- 조건에 맞는 주사위를 연속으로 써야 콤보가 이어진다.
- 전사는 3단계 최종 보상을 직접 발동하고, 도적은 1단계까지만 체험한다.

## 데모 전투 구성

- 파티는 전사와 도적 두 명이다.
- 구역 0에는 파란 슬라임, 구역 1~3에는 초록 슬라임을 한 마리씩 배치한다.
- 파란 슬라임의 박치기는 무작위 캐릭터의 좌우 2칸까지 공격한다. 두 캐릭터가 모인 뒤 실제 박치기 의도를 다시 선택해 현재 위치를 기준으로 범위를 예고하고, 1턴 종료 시 두 캐릭터 모두 방진의 피해 감소를 확인하게 한다.
- 네 몬스터는 전사의 3단계 예상 피해와 같은 체력으로 시작하며 3단계 직전까지 사망하지 않는다. 마지막 이동 직전에 사망 방지를 해제해 대지 가르기가 네 몬스터를 동시에 처치한다.
- 이 체력과 무적 처리는 스폰된 런타임 스탯에만 적용하며 MonsterPreset 원본은 변경하지 않는다.

## 진행 흐름

### 전투 기초

1. 몬스터의 다음 행동 아이콘과 정보 패널을 확인한다.
2. 네 구역의 경계색과 구역별 담당 몬스터를 확인한다.
3. 위험 타일이 몬스터의 다음 공격 범위임을 확인한다.
4. 턴 시작 시 주사위가 자동으로 굴러가며, 캐릭터마다 한 턴에 한 번 배정할 수 있음을 안내한다.
5. 이동이 끝나면 별도의 공격 버튼 없이 도착한 구역의 몬스터를 자동으로 공격한다고 안내한다.

### 1턴: 자동공격, 1단계 콤보, 위치 패시브

- 주사위는 `[4, 2, 5, 3]`으로 고정한다.
- 전사를 선택하고 눈 4로 이동시킨다. 실제 콤보 이벤트가 `전사, stage=1, Advanced`를 보고할 때만 다음 단계로 넘어간다.
- 콤보 핍이 다음 단계를 나타내며 조건에 맞는 주사위를 연속 사용해야 진행된다고 설명한다.
- 도적을 선택하고 눈 2로 전사와 같은 구역에 이동시킨다. 실제 콤보 이벤트가 `도적, stage=1, Advanced`를 보고할 때만 다음 단계로 넘어간다.
- 쌍비수의 2회 공격과 협공 `+30%` 알림으로 도적 패시브를 체험한다.
- 같은 구역의 다른 아군 한 명마다 협공은 도적 공격 피해 `+30%`, 방진은 그 구역 아군이 받는 공격 피해 `-10%`로 중첩된다고 설명한다.
- 턴을 종료하고 파란 슬라임의 박치기를 받아 방진 `-10%` 알림과 실제 감소 피해를 확인한다.

### 2턴: 전사 2단계

- 다음 플레이어 턴의 주사위는 `[4, 1, 5, 6]`으로 고정한다.
- 전사를 선택하고 눈 4로 이동시킨다.
- 실제 콤보 이벤트가 `전사, stage=2, Advanced`를 보고할 때만 다음 단계로 넘어간다.
- 지진파가 현재 구역과 양옆 구역의 몬스터를 공격한다는 것을 화면에서 확인한다.
- 도적은 이동하지 않고 턴을 끝낸다. 도적 콤보가 미이동으로 초기화되는 현상을 별도 조작 없이 보여 주고 규칙 정리에서 설명한다.

### 3턴: 전사 최종 보상

- 다음 플레이어 턴의 주사위는 `[4, 2, 3, 6]`으로 고정한다.
- 최종 이동 단계에 들어갈 때 네 몬스터의 사망 방지를 해제한다.
- 전사를 선택하고 눈 4로 이동시킨다.
- 실제 콤보 이벤트가 `전사, stage=0, Finished`를 보고하면 완료 안내로 넘어간다. 마지막 적 사망이 콤보 보고보다 먼저 전투를 끝내는 현재 전투 순서에서는 네 몬스터 전멸도 같은 실제 성공으로 인정한다.
- 대지 가르기가 모든 구역의 몬스터를 처치하고 모든 아군에게 방어도를 부여하는 것을 확인한다.

### 규칙 정리

- 조건에 맞지 않는 주사위를 사용하면 기본 공격은 하지만 진행 중인 콤보는 끊긴다.
- 이동한 구역에 공격할 몬스터가 없어도 콤보가 끊긴다.
- 한 턴 동안 해당 캐릭터를 이동시키지 않아도 콤보가 끊긴다.
- 튜토리얼이 끝나거나 건너뛰어지면 주사위 잠금, 행동 잠금, 이벤트 구독, 런타임 데모 유닛을 모두 정리한다.

## 구조

- `TutorialCombatProgress`는 전사/도적의 콤보 이벤트를 받아 튜토리얼 완료 플래그만 관리하는 순수 상태 객체다.
- `TutorialScenario`는 데모 스폰, 주사위 대본, 런타임 체력 조정, UI 단계 조립과 이벤트 구독 수명을 담당한다.
- `TutorialDirector`와 일반 전투 시스템은 변경하지 않는다. 튜토리얼도 실제 이동, 자동공격, 패시브, 몬스터 턴, 콤보 이벤트를 그대로 사용한다.

## 검증

- 상태 객체가 잘못된 캐릭터, 잘못된 단계, 끊김 이벤트에는 진행하지 않는지 자동 테스트한다.
- 올바른 전사 1·2·3단계와 도적 1단계 이벤트만 각각 플래그를 완료하는지 자동 테스트한다.
- 튜토리얼 프리팹에 전사, 도적, 파란 슬라임, 초록 슬라임 참조가 모두 연결됐는지 에디터 테스트에서 확인한다.
- Unity 컴파일, 자가 테스트, 실제 튜토리얼 플레이로 네 구역 배치와 최종 전멸까지 확인한다.
